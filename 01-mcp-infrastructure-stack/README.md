# Módulo 01: Infraestrutura de Servidores MCP em OCI Container Instances
# Module 01: MCP Server Infrastructure on OCI Container Instances

---

## 🇧🇷 Português (PT-BR)

### Visão Geral
Este módulo automatiza o provisionamento da infraestrutura base para execução de servidores **Model Context Protocol (MCP)** em **OCI Container Instances**[cite: 5], incluindo alocação de recursos flexíveis de CPU/Memória e políticas IAM.

### Recursos Provisionados:
- **OCI Container Instance:** Instância de contêiner dedicada para execução das imagens Docker dos servidores MCP[cite: 5].
- **Configuração de Hardware:** Definição de OCPUs e memória RAM alocada para execução dos serviços[cite: 5].
- **Rede e Segurança:** Subnets e regras de segurança necessárias para a comunicação do cliente de IA com o servidor MCP[cite: 5].

## 🇺🇸 English (EN)

### Overview
This module automates the foundational infrastructure provisioning for running **Model Context Protocol (MCP)** servers on **OCI Container Instances**[cite: 5], including allocation of flexible CPU/Memory resources and IAM security policies.

### Provisioned Resources:
- **OCI Container Instance:** Dedicated container instance host for running MCP server Docker images[cite: 5].
- **Hardware Configuration:** Allocation of OCPUs and RAM memory required for service execution[cite: 5].
- **Networking & Security:** Subnets and security rules required for AI Client to MCP server communication[cite: 5].
